# BilleteraDistribuida

Proyecto final de Aplicaciones Distribuidas — ESPE.

Billetera móvil con depósito, retiro, transferencia y pago de servicios.

## Tecnologías previstas

- Backend: Python, FastAPI, SQLite y WebSockets.
- Android: Kotlin, Jetpack Compose, Room y corrutinas.

## Organización

- backend/: API REST, persistencia y notificaciones.
- android/: aplicación móvil nativa.
- docs/: documentación y evidencias.

## Estado

Preparación del entorno e inicio del desarrollo.
